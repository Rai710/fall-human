# Video lokal

Letakkan video percobaan di folder ini atau pilih video dari folder mana pun.
File video tidak dimasukkan ke Git. Aplikasi tidak memindahkan atau mengubah video asli.

Jika menggunakan GMDCSA-24, cantumkan sumber di laporan:
https://zenodo.org/records/13354453

File sampel pengujian, jika ada, berasal dari:
https://github.com/ekramalam/GMDCSA24-A-Dataset-for-Human-Fall-Detection-in-Videos
Pertahankan atribusi dan periksa cakupan lisensi sebelum membagikan ulang data.
